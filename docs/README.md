# Tài Liệu Đặc Tả Đề Tài

Thư mục này chứa các tài liệu đặc tả, phân tích và thiết kế hệ thống cho đồ án.

## Cấu Trúc

| File/Folder | Mô tả |
|-------------|-------|
| *(đặt file đặc tả vào đây)* | Đặc tả yêu cầu, thiết kế hệ thống, ... |

> Đặt các file đặc tả đề tài (.docx, .pdf, .md) vào thư mục này.
